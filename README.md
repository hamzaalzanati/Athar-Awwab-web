# أثر أواب — الموقع ولوحة التحكم

موقع عام + لوحة تحكم (تطبيق تيليجرام) بـ HTML وجافاسكربت عادي، ويعمل على **Vercel (الخطة المجانية)**.
قاعدة البيانات: **Supabase**. لا React ولا Next ولا خطوة بناء.

```
website/
  vercel.json          توجيه الروابط (/channels/اسم → الصفحة) وترويسات الأمان
  api/page.js          كل صفحات الموقع (HTML من الخادم، جيد لمحركات البحث)
  api/admin.js         كل عمليات لوحة التحكم (يتحقق من هوية تيليجرام على الخادم)
  api/media.js         يجلب الصورة المصغّرة لمعاينة المنشورات عند الطلب
  api/contact.js       نموذج التواصل        api/track.js   إحصاء مجهول (بلا IP)
  lib/                 منطق مشترك (بحث، عرض، زناتي، تحقق)
  public/              CSS وJS والصور   |   public/tg/ = لوحة التحكم
../database/schema.sql  ملف القاعدة الوحيد
```

## التشغيل خطوة بخطوة

**1) قاعدة البيانات (Supabase)** — إن كنت شغّلت الملف سابقًا فأعد تشغيله بعد كل تحديث (آمن، يضيف الجديد فقط)
1. أنشئ مشروعًا في supabase.com.
2. افتح *SQL Editor* ← *New query* ← الصق محتوى `database/schema.sql` كاملًا ← *Run*. (آمن لإعادة التشغيل.)
3. من *Settings ← API* انسخ `Project URL` و`service_role key` (سرّي).
4. أضف نفسك مالكًا (غيّر الرقم إلى معرّفك في تيليجرام — اعرفه من @userinfobot):
   ```sql
   insert into admins (telegram_user_id, name, role) values (123456789, 'اسمك', 'owner');
   ```

**2) Vercel**
1. ارفع مجلد `website` على GitHub، ثم في Vercel: *Add New Project* ← اختر المستودع (إن كان المجلد داخل مستودع أكبر فاجعل *Root Directory* = `website`). *Framework Preset*: Other.
2. أضف المتغيرات من `.env.example` (*Settings ← Environment Variables*): `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `TELEGRAM_BOT_TOKEN`, `SITE_URL`.
3. *Deploy*. افتح الرابط: يجب أن تظهر الصفحة الرئيسية (فارغة من الأقسام حتى تضيف محتوى).

**3) ربط لوحة التحكم بالبوت**
في @BotFather: `/mybots` ← بوتك ← *Bot Settings* ← *Menu Button* ← الصق `https://نطاقك/tg/`. وفي استضافة البوت اضبط `ADMIN_WEBAPP_URL` بنفس الرابط، فيفتحها الأمر `/admin`.
اللوحة لا تعمل إلا من داخل تيليجرام، وكل طلب فيها يُتحقق منه على الخادم (توقيع initData + جدول `admins` + الدور).

## تعبئة المحتوى (الموقع يبدأ فارغًا عمدًا: لا بيانات وهمية)
0. **استيراد من روابط تيليجرام (الأسهل):** *المزيد ← استيراد قائمة جاهزة ← روابط*، الصق الروابط كما هي (قنوات، جروبات، روابط دعوة خاصة، بوتات، حزم ملصقات، وحسابات التواصل). يجلب النظام الاسم والوصف والعدد والصورة من صفحة كل رابط، ويحدد النوع ويقترح التصنيف، ويضبط العلاقة «من مشروعنا». ملف `starter-import.txt` فيه روابطك جاهزة.
1. **استيراد قائمة منسّقة:** في اللوحة *المزيد ← استيراد قائمة جاهزة*، الصق سطرًا لكل عنصر: `النوع | الاسم | @المستخدم | التصنيف | العلاقة | وصف`.
   مثال: `قناة | قرآن بصوت متنوع | @quran_demo | قنوات محتوى القرآن متنوع | من مشروعنا | تلاوات مختارة`. للملصقات اكتب اسم الحزمة (آخر جزء من رابط addstickers).
   يتخطى المكرر ويذكر سبب كل سطر مرفوض، ولا يحذف شيئًا. نفس الفكرة للمواقع/المشاريع/«ساعد» وحسابات التواصل.
2. **اكتشاف تلقائي:** أضف البوت مشرفًا في قناتك أو جروبك ← يظهر في *الموافقات* ← اختر العلاقة والتصنيف ← قبول.
3. **يدويًا:** *الكيانات ← إضافة كيان يدويًا* (للبوتات والملصقات).
بعد الإضافة تظهر الأقسام تلقائيًا (القنوات والبوتات والجروبات والملصقات مجمّعة حسب التصنيف، ومواقعنا، والحسابات...).

## تغيير الصور
استبدل الملف **بنفس الاسم** في `public/images/` وارفعه على GitHub:
`hero.jpg` (خلفية الواجهة) · `og.jpg` (معاينة المشاركة 1200×630) · `logo.png` (الشعار) · `logo-512.png` (للبوت من BotFather: `/setuserpic`) · `logo-light.png` (للخلفيات الفاتحة) · `icon.png`/`apple-icon.png` (أيقونات).
أو غيّر صورة الواجهة من اللوحة: *المزيد ← صورة الواجهة* (رابط https فقط؛ لا تُرفع صور إلى القاعدة).

## ما تفعله اللوحة (`/tg/`)
- **النظرة:** حالة البوت وقاعدة البيانات، صحة النظام (آخر مزامنة، المتعثر، طابور المهام، استخدام الذكاء الاصطناعي)، التنبيهات مع زر «معلوم، لا تكرّر».
- **الموافقات:** كيانات اكتشفها البوت ← اختيار العلاقة والتصنيف ← قبول/رفض.
- **الكيانات:** بحث وتصفية وتصفح بصفحات، تعديل كامل، إضافة يدوية، معاينة تيليجرام (1–3 رسائل)، سجل المزامنة، مزامنة كيان واحد، تنبيه «بلا تصنيف».
- **المحتوى:** مشاريع وقسم «ساعد» · قسم «ساهم» · حسابات التواصل · التصنيفات (ترتيبها مستقل).
- **زناتي:** يجيب من بيانات المشروع الحقيقية (Gemini اختياري).
- **المزيد:** الإحصاءات (زيارات/نقرات/أكثر الصفحات والكيانات/بحث بلا نتائج مع المقارنة بالفترة السابقة) · بث إعلان · المهام والمزامنة (إعادة المحاولة/إلغاء) · رسائل التواصل (قراءة/حذف) · مستخدمو البوت (حظر داخلي وملاحظات) · **المشرفون وصلاحياتهم** (للمالك) · الاستيراد · الإعدادات · سجل التدقيق.
- يظهر رقم الإصدار بجانب دورك في أعلى اللوحة (`v4`)؛ إن لم تره فأنت تشغّل نسخة قديمة: أعد النشر وأغلق اللوحة وافتحها من جديد.

## الأدوار
`editor`: المحتوى والكيانات والمعاينة · `admin`: + الإعدادات والتصنيفات والتواصل والمستخدمين والمزامنة وزناتي · `owner`: كل شيء.

## زناتي والذكاء الاصطناعي (اختياري)
بدون مفاتيح Gemini يجيب بأرقام حقيقية مباشرة. مع المفاتيح: الأسئلة البسيطة ← `gemini-3.5-flash-lite`، والتقارير والمقارنات ← `gemini-3.6-flash`،
بميزانية يومية (150 / 40 استدعاء) وتبديل تلقائي بين حتى 3 مفاتيح. لا يصدر فتاوى، ويقول «الأدلة غير كافية» حين لا تكفي البيانات.

## الاختبارات
`npm install && npm test` (62 اختبارًا: التحقق من initData والصلاحيات، الهروب من HTML، البحث، زناتي، وكيل الصور).
