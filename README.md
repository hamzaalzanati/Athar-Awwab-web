# بوت أثر أواب — Node.js + grammY

مشروع مستقل عن الموقع، بيتصل معاه بس عن طريق قاعدة بيانات Supabase المشتركة.

## معمارية المشروع (محدّثة)

- **الموقع + لوحة التحكم**: مستضافين مع بعض على Vercel (نفس مشروع `athar-awwab-website`)
- **البوت** (المشروع ده): مستضاف منفصل على أي استضافة بتشغّل Node.js
  بشكل دائم (Railway/Render/Fly.io) — لأنه محتاج يفضل شغال يستقبل رسائل
  وينشر تلقائي، وده مش شغل السيرفرلس (Vercel)
- **قاعدة البيانات**: Supabase واحدة مشتركة بين الاتنين

## التشغيل محليًا

```
npm install
cp .env.example .env    # املأ القيم بعدين
node index.js
```

## الاستضافة (مجانًا)

البوت ده بيشتغل بنظام Long Polling (مش Webhook)، يعني محتاج استضافة
بتشغّل عملية Node.js بشكل دائم. خيارات مجانية مناسبة:

- **Railway** (railway.app) — أسهلهم، بس فيه حد ساعات شهري في الخطة المجانية
- **Render** (render.com) — Background Worker مجاني، بينام لو مفيش نشاط ويصحى تاني
- **Fly.io** — VM صغيرة مجانية

خطوات عامة لأي منهم:
1. ادفع المشروع ده لـ GitHub (repo منفصل عن الموقع)
2. اربط الاستضافة بالـ repo
3. ضيف متغيرات البيئة (نفس اللي في .env.example) في إعدادات الاستضافة
4. Start Command: `node index.js`

## الأوامر المتاحة

| الأمر | الوظيفة |
|---|---|
| `/start` `/menu` | القائمة الرئيسية |
| `/channels` | تصفح القنوات |
| `/bots` | تصفح البوتات |
| `/random` | اقتراح عشوائي |
| `/search <كلمة>` | بحث في الكتالوج |
| `/invite` | رسالة دعوة جاهزة |
| `/hijri` | التاريخ الهجري اليوم |
| `/ayah` | آية اليوم |
| `/question` | سؤال اليوم الديني |
| `/zakat <مبلغ>` | حاسبة الزكاة |
| `/short <رابط>` | رابط مختصر (محتاج Supabase) |
| `/whereis <id>` | في أي قنواتك المستخدم ده عضو (أدمن بس) |
| `/stats` | إحصائيات (أدمن بس) |
| `/announce <نص>` | إضافة إعلان لطابور النشر لكل القنوات (أدمن بس) |
| `/globalban <id>` | حظر مستخدم من كل القنوات المُدارة (أدمن بس) |
| `/admin` | يفتح لوحة التحكم (المالك/OWNER_ID بس) |

## لوحة التحكم

بقت في مشروع الموقع (`athar-awwab-website/dashboard/`)، بتتفتح من زرار
`/admin` هنا في البوت، وكل الـ API بتاعتها (`api/admin/*`) موجودة في
مشروع الموقع كمان — محتاجة نفس `BOT_TOKEN` و`ADMIN_IDS` و`SUPABASE_URL`
و`SUPABASE_KEY` مضافين في إعدادات Vercel بتاعة الموقع.
